# Research release and verification policy

## Counting rule
A repository directory, manuscript, numerical example, conjecture and externally validated theorem are different units. Never count them interchangeably.

## Scientific gates
1. SOURCE-LOCK: preserve original claim, source, hypotheses, conventions and historical partial results.
2. HYPOTHESIS: formulate a falsifiable theorem with explicit quantifiers.
3. DESTRUCTION: search boundary counterexamples and wrong-normalization mutations.
4. PROOF: isolate analytic logic from computer-assisted finite gates.
5. INDEPENDENT REPLAY: exact rational arithmetic, independent solver, or actual proof kernel as appropriate.
6. PRIOR ART: check original source and subsequent mathematical literature; failure to find an earlier result does not establish priority.
7. RELEASE OR HOLD: publish the correct confidence status and unresolved dependencies.

## Status vocabulary
- TARGET: statement selected, not attacked.
- EXPERIMENTAL: computational pattern only.
- CANDIDATE: mathematical argument assembled and internal tests passed.
- FORMALLY VERIFIED: compiled in a trusted proof kernel with toolchain and log supplied.
- SPECIALIST REVIEWED: substantive independent mathematical review documented.
- ACCEPTED: external publication or equivalent independent acceptance.
- REFUTED: exact counterexample found to a proposed assertion.

A checked numerical example is not a universal theorem. A passing Python test is not Lean proof certification. A stronger theorem about an already disproved conjecture is **not** a first disproof.

Third-party papers and code retain original attribution and copyrights.
