# Case 001 — exact certificate

The full JSON certificate is generated by running:

    python cases/001/verify.py --max-n 160

Its critical acceptance checks use Python's exact fractions.Fraction and rational Taylor enclosures. GitHub Actions also regenerates verification.json for every publication-PDF build.

### Analytic base-case inequalities

- Odd cycles, n=15: strict margin greater than 506/11025.
- Even cycles, n=16: strict margin greater than 1733/58800.

Monotonicity in the paper proves every larger case in each parity family. The exact finite converse checks n=3 through n=14. The separate numerical Fourier sweep is a sanity check, not evidence of an all-n theorem.

The produced JSON records tested ranges, exact results, and nonproof numerical cross-checks. A compiled PDF and JSON are offered as GitHub Actions artifacts if the build succeeds.
