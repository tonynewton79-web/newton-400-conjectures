# Paper 001 — sharp cycle classification (18 October 2026)

This directory holds Tony Newton's revised research edition **Cycle Gravity Spectra and the Sharp Cycle Classification for Graffiti 197**, with a separate exact-certificate supplement.

## Publications and files

- [Main manuscript PDF](main.pdf) and [LaTeX source](main.tex): three-page proof of the sharp cycle threshold C_n for n>=15 and a convex radial-kernel Gram extension.
- [Exact certificate supplement](verification_supplement.pdf) and [LaTeX source](verification_supplement.tex): twelve rational C3–C14 finite certificates, and a correctly delimited Stage 15 Lean record.
- [Combined 5-page PDF](Paper001_Complete_Research_Packet_2026-10-18.pdf), generated by the paper CI job.
- [Standalone rational verification script](exact_certificate.py) and its generated [JSON proof record](exact_certificate.json).

The original refutation of Graffiti 197 is due to Roucairol and Cazenave. Novelty of this sharpening and of the convex-kernel extension has not been independently assessed.

## Run exact verification

```bash
python3 exact_certificate.py exact_certificate.json
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error verification_supplement.tex
pdflatex -interaction=nonstopmode -halt-on-error verification_supplement.tex
```

The precise 15-stage Lean status is tracked at [Issue #12](https://github.com/tonynewton79-web/newton-400-conjectures/issues/12). Stage 15 confirms exact harmonic shell counts and row sums; the final actual-spectrum bridge, ordered adjacency eigenvalue gate, and C3–C14 formalization are **still open**. Mathematical written proof and complete Lean kernel certification are separate claims.

The new edition supersedes but does not retract the earlier two-page note already sent to the conjecture's authors. The present manuscript is a research preprint for independent specialist review; it is not yet a refereed publication.
